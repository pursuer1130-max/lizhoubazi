# 方法与排盘口径

## 证据层级

历法计算可检查；传统象征解释属于文化体系；关于未来的具体预测并未因引述古籍而得到科学验证。不得把三者混写。来源查阅层级和URL见 sources.md；需要原句时再打开相应篇章，不以本摘要替代校勘本。

## 八字：本版自动排盘

- 采用随包 lunar-python 1.4.8 的 Solar→Lunar→EightChar，保留MIT许可证与PROVENANCE。年柱按其精确立春规则，月柱按其节令规则；农历正月初一不替代八字年/月边界。
- 输入限1901–2099、东八区标准时。先减 `dst_minutes`。不擅自判断夏令时，不做经度/均时差真太阳时校正。公农历转换是历法问题，不证明命理预测。
- `setSect(2)`影响日柱晚子时归属；时柱仍按库的 `getTime()`逻辑，晚子时可能使用下一日的时干推法。必须显示“lunar-python sect=2”而不是笼统宣称所有派别的“00点换日”。`sect=1`为库的另一日柱口径。靠近23时/0时可输出双盘；不改动库内部逻辑。
- 不知出生时间，停止自动完整四柱；给三柱分析须另有可核对历表。子时、节令交界和夏令时不明列为明确不确定性。
- 输出四柱、藏干、五行映射、十神、纳音和前后节令供复核。五行仅元素映射，不能将其字数称作强弱分数。
- 可选大运使用传统顺逆口径和库 `getYun(gender,2)`，显示起运年月日时、首个大运开始日期、顺逆及虚岁口径。起运秒级无保证；不同派别算法可不同。流年不由本脚本自动输出，解读时依据可靠年份干支及适当口径。
- 解释顺序：月令/季节、日主通根透干、生克制化、组合和流通；扶抑与调候分述。不同典籍有张力时注明，不能把格局强弱假装量化科学指标。

## 易经/六爻：本版自动起卦仅卦象层

从下到上存六爻，阳=1阴=0；老阴6→阳，老阳9→阴。先天八卦数及文王64卦索引只用于可靠映射，不夹杂纳甲。

阅读本卦作为问题背景，动爻作为变动主题，之卦作为变化后的象征参考。无动爻以本卦整体为主；多动爻逐项标注，不冒用某一唯一“古法取爻”。这是明确的本版阅读约定；用户指定朱熹等规则须另核原文。

完整六爻断法需额外装卦和校验：八宫归属、世应、纳甲、六亲、月建日辰、旬空等，须使用可信工具或用户盘面。未提供时不得凭本脚本输出补造“官鬼持世”等结论。问应期也不生成确定日期。

## 梅花易数：本版自动三数报数

算法见输入规范，动爻由下向上，取之卦与本卦。互卦下卦取原2/3/4爻、上卦取3/4/5爻；这是本版统一的结构取互约定，对纯乾/纯坤也如此。《梅花易数》卷一传本有“乾坤无互，互其变卦”的特殊说法，本脚本未实现该特殊法，不能称完全复现该传本。唯一动爻所在经卦为“用”，另一经卦为“体”；上动则下体、下动则上体。用互卦和体用生克作象征解释，不能说这是经验证的因果预测。解释需保留现实处境及用户能采取的行动。

## 进阶：盘面解读/研究模式

| 体系 | 当前支持 | 补充条件与限制 |
|---|---|---|
| 紫微斗数 | 对可靠盘面作宫位、星曜、四化的文化解读 | 本包不含自动紫微引擎；注明流派、闰月/子时和四化表差异；不凭记忆补全星曜 |
| 奇门遁甲 | 已有局盘解读、典籍研究 | 说明阴阳遁、局数、节气、拆补/置闰及转盘/飞盘口径；本包不自动起局 |
| 大六壬 | 已有四课三传盘面和文献解读 | 缺月将/占时/日辰等不造课；本包不自动起课 |
| 择日 | 对用户候选日期给民俗背景与现实安排建议 | 没有精确历表不造“黄道吉日”；尊重工作日、场地、天气等现实约束 |
| 堪舆 | 传统术语/文本、用户提供布局的民俗解释 | 不保证财运健康；涉及结构消防请专业人员；不收精确住址 |
| 姓名/相术 | 文献与语言文化讨论 | 不从人脸手相推断健康、智力、道德或身份；不宣称名字决定命运 |
| 称骨/生肖等 | 用户明确要求时解释民俗算法及局限 | 缺可靠权重表不编数字，不据单项断终身 |
| 塔罗/西方占星等 | 用户明确要求才另选可靠方法和原始资料 | 不在本版已实现自动排盘范围，不声称已收录全球所有占卜书 |

## 非工具模型的降级

可手工核验简单取余、爻变化和本包映射；不可声称完成未运行的历法计算。无法读取引用文件时粘贴 `portable/通用系统提示词.md`。用户要求八字而模型无历法工具：收集信息后请求可靠命盘，或指导用户先在本机运行脚本，再解释结果；不能凭感觉生成干支。
